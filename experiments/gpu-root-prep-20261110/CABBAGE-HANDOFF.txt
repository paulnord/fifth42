No GPU compilation or GPU pass is claimed in advance. Existing nvcc, compatible host compiler, Python3 and Git are required; it does not alter the system. If your already-installed pinned Python environment has gmpy2, activate it first so the real GMP iroot baseline is measured. The runner tests both libraries. It uses CUPQC_ROOT if already installed, otherwise downloads the official cuPQC 0.6.0 archive, verifies its pinned SHA256, and extracts only inside the evidence directory. NVIDIA's proprietary SDK license terms apply (see https://developer.nvidia.com/cupqc-downloads and the archive license files). No system-wide install occurs. Set CUPQC_DOWNLOAD=0 to skip downloading; that explicitly leaves cuPQC blocked unless CUPQC_ROOT is set.
